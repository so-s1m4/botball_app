# 3D-модели Botball 2026

156 устанавливаемых позиций: 101 LDraw, 16 KIPR Simulator, 39 приближённых моделей. Связь с каталогом, габариты и происхождение: `models.json`. Модели OBJ/MTL работают офлайн после импорта Godot. Единицы — метры, +Y вверх, XZ центрированы, основание сетки Y=0. Цвета LEGO условные: цветовой состав набора не извлечён из PDF.

## LDraw

Использована официальная библиотека [LDraw.org](https://www.ldraw.org/), загруженная из https://library.ldraw.org/library/updates/complete.zip. SHA-256 архива записан в манифесте. Авторы, редакторы и лицензия каждого компонента указаны в оригинальных DAT-файлах в `ldraw_sources.zip`. Приложены CAreadme.txt, CAlicense.txt и CALicense4.txt. Преобразованные модели сохраняют лицензии оригинальных компонентов (CC BY 2.0 и/или CC BY 4.0 согласно заголовкам).

Изменения: рекурсивное применение преобразований, триангуляция четырёхугольников, учёт BFC и зеркальных ссылок, переход из LDU в метры, поворот в систему Godot, центрирование. Линии/условные линии, текстуры и исходные цвета не включены; геометрия отверстий, штифтов и зубьев сохранена.

Повторная генерация LEGO и приближённых моделей:

```sh
python3 scripts/build_part_models.py /path/to/complete.zip
```

## KIPR Simulator

Источник: [kipr/Simulator](https://github.com/kipr/Simulator), файл `static/object_binaries/demobot_v6.glb`. Коммит, SHA-256, имена выделенных узлов и лицензия указаны в архиве/манифесте. Лицензия GPL-3.0: `KIPR_LICENSE.txt`. Полный исходный GLB и скрипт преобразования включены в `kipr_sources.zip`.

Изменения: распаковка Draco, выделение деталей, применение преобразований дочерних узлов, центрирование, экспорт OBJ/MTL с цветами материалов. Из модели Wombat исключена отдельная батарея; из колеса исключён отдельный крепёж. Размеры — из исходного симулятора, без независимой проверки физического образца.

После первой генерации запусти импорт KIPR, чтобы заменить соответствующие приближённые модели:

```sh
npm install --prefix /tmp/botball-model-tools draco3dgltf@1.5.7
NODE_PATH=/tmp/botball-model-tools/node_modules node scripts/import_kipr_models.cjs /path/to/demobot_v6.glb
```

## Приближённые модели

Сгенерированы в `scripts/build_part_models.py`. Размеры электроники, отверстий, шасси и крепежа являются оценками. Эти модели помечены `estimated`, показаны с надписью «Приближённая модель». Использовать их как проверенные чертежи для изготовления или подтверждение собираемости нельзя.

В версии геометрии 2 добавлены нормали с порогом сглаживания 50°, фаски оценочной электроники, отверстия с 32 сегментами и крепёж с видимой резьбой. Боковые панели каналов и шасси исправлены: длина направлена вдоль Z, высота вдоль Y. Исходные сетки LDraw/KIPR не меняются, добавляются нормали. Скрипт обработки: `scripts/refine_part_models.py`.
