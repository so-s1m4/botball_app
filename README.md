# Botball Simulator

Настольный 3D-симулятор для подготовки к Botball / ECER 2027.

## Текущее состояние

Начальный репозиторий проекта для Godot 4 и GDScript. Стартовая сцена показывает статус разработки. Физика робота, импорт стола, задания, подсчёт очков, конструктор и оптимизация пока не реализованы.

## Запуск

1. Установить Godot 4 с поддержкой GDScript.
2. В менеджере проектов выбрать «Импортировать» и открыть `project.godot`.
3. Запустить проект клавишей F6 (сцену) или F5 (проект).

Godot в текущей среде не установлен; запуск движка здесь не проверен.

## Цель

- Загрузка предоставленных пользователем моделей GLB/GLTF и настройка масштаба, объектов и коллайдеров.
- Отдельные профили столов, физических параметров и правил.
- Роботы из подтверждённого комплекта Botball с учётом количества деталей.
- Ручное управление, автономные программы, датчики и объяснимый подсчёт очков.
- Поиск маршрутов, затем сравнение допустимых конструкций с повторными испытаниями.
- Русский интерфейс и сохранение проектов.

## Структура

- `scenes/` — сцены приложения.
- `src/` — код интерфейса, симуляции и дальнейших модулей.
- `assets/models/` — предоставленные модели столов и деталей.
- `data/tables/` — профили столов.
- `data/kits/` — проверенные списки деталей по годам.
- `data/rules/` — правила и условия начисления баллов.
- `docs/` — архитектура, этапы и статус исходных данных.

План: [docs/ROADMAP.md](docs/ROADMAP.md). Архитектура: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Исходные данные: [docs/SOURCES.md](docs/SOURCES.md).

## Принцип достоверности

Неизвестные размеры, физические параметры и ограничения отмечаются как предположения. Результаты симуляции и испытаний настоящего робота хранятся отдельно. Лучший найденный вариант не считается абсолютным максимумом.
